# 🏠 NYC Airbnb Room Type Prediction

An end-to-end Machine Learning project that predicts the room type of an Airbnb listing based on listing features.

## 🚀 Live Demo

👉 [Open Live Application]("https://nyc-airbnb-room-type-predictor.onrender.com")

## 🔗 Backend API

👉 [FastAPI Backend](https://nyc-airbnb-room-type-predictor.onrender.com)

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- HTML
- CSS
- JavaScript
- Render

## ✨ Features

- Airbnb room type prediction
- Interactive web interface
- ML model integrated with FastAPI
- REST API for predictions
- Deployed frontend and backend
